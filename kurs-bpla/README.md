# Курс оператора БПЛА

Автономный статический лендинг курса операторов БПЛА. Страница не использует формы и телефон: связь ведётся напрямую через MAX и Telegram.

## Локальный запуск

```powershell
python -m http.server 8011
```

После запуска откройте `http://127.0.0.1:8011/`.

## Состав

- `index.html` — основная страница;
- `privacy.html` — политика обработки данных;
- `course.css` — адаптивный дизайн;
- `course.js` — мобильное меню, cookie consent, Яндекс Метрика и цели;
- `assets/` — оптимизированные изображения и иконки.

## Аналитика

Яндекс Метрика № `113018498` загружается только после согласия посетителя. События:

- `course_max_click`;
- `course_telegram_click`;
- `course_faq_open`.

Выбор аналитики хранится 7 дней в cookie `bpla_course_analytics`.

## Публикация

Боевая версия предназначена для адреса `https://obuchenie-bpla.ru/`; он указан в `canonical`, Open Graph, `robots.txt` и `sitemap.xml`. Указанные на странице условия трудоустройства и выплат сопровождаются оговоркой: они зависят от результатов отбора, вакансии и условий работодателя. Перед изменением предложений нужно подтвердить расписание, оборудование, итоговый документ и условия работодателя.

Все основные иллюстрации созданы специально для этой страницы. Референсы использовались только как направление композиции и цвета.
