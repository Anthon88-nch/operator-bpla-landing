# Лендинг «Оператор БПЛА по контракту»

Статический адаптивный сайт без CMS и production-зависимостей. Откройте `index.html` для локального просмотра или разместите содержимое папки на сервере.

## Перед публикацией обязательно заменить

- `[НАЗВАНИЕ]`, `[НАЗВАНИЕ ОРГАНИЗАЦИИ]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[АДРЕС / РЕГИОН]`, `[ГРАФИК РАБОТЫ]`;
- `[СУММА]`, `[СРОК]`, `[РЕГИОН]` — только по подтвержденным официальным условиям;
- `example.invalid` в `sitemap.xml` и JSON-LD;
- шаблон `privacy.html` на согласованную политику фактического оператора данных.

## Форма

Сейчас форма работает в демонстрационном режиме и **не отправляет данные**. Перед запуском нужно подключить защищенный обработчик/CRM, серверную валидацию, антиспам, журнал согласий и уведомление ответственного сотрудника. Не помещайте токены и пароли в `app.js`.

## SEO и аналитика

После утверждения домена добавьте canonical, абсолютный `og:image`, строку Sitemap в `robots.txt`, цели Яндекс Метрики и фактические реквизиты организации. Счетчики и рекламные скрипты в прототип намеренно не добавлены.
