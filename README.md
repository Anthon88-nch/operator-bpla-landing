# Лендинг «Оператор БПЛА по контракту»

Статический адаптивный лендинг без CMS и сборки: чистые HTML, CSS и JS. Боевая версия работает на домене `svo.tatar`; этот репозиторий — зеркало статического контента, которое можно просматривать через GitHub Pages.

## Состав

- `index.html` — основная страница лендинга;
- `styles.css`, `app.js` — стили и логика (мобильное меню, форма, cookie-согласие, Яндекс Метрика после согласия);
- `privacy.html` — политика обработки персональных данных;
- `personal.html` — согласие на обработку персональных данных;
- `consent.html` — условия согласия на связь;
- `attention.html` — страница «Почему нет телефона»;
- `assets/` — изображения, иконки, видео и логотипы партнёров;
- `kurs-bpla/` — автономный суб-лендинг курса операторов БПЛА со своими стилями и ассетами.

## Локальный запуск

```powershell
python -m http.server 8010
```

После запуска откройте `http://127.0.0.1:8010/`. Суб-лендинг курса доступен по адресу `http://127.0.0.1:8010/kurs-bpla/`.

## Индексация

Репозиторий в демонстрационном режиме: `robots.txt` запрещает обход (`Disallow: /`), а `sitemap.xml` не содержит URL. Поисковый трафик ведёт на боевой домен `svo.tatar`, указанный в canonical и og:url. Перед использованием копии на собственном домене снимите ограничения и обновите canonical, og:url и sitemap.

## Форма обратной связи

Форма отправляет заявки на серверный обработчик `/api/contact`, который не входит в этот репозиторий. На статическом хостинге (включая GitHub Pages) отправка формы недоступна — посетителям показываются прямые контакты в MAX и Telegram. Не помещайте токены и пароли в `app.js`.

## Аналитика

Счётчик Яндекс Метрики подключается только после явного согласия посетителя в баннере cookie. Электронная коммерция отключена.
